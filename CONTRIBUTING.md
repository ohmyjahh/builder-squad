# Contribuição

Este é um produto proprietário. Contribuições externas dependem de autorização do mantenedor e não concedem direito de redistribuição.

## Fluxo técnico

1. Abra ou associe uma story.
2. Preserve escopo e ownership.
3. Atualize File List e checkboxes.
4. Adicione ou atualize testes.
5. Execute validate, test e doctor.
6. Documente mudança quebradora e migração.
7. Use commit convencional com ID da story.

## Regras

- tasks antes de novos comandos de agente;
- core neutro, particularidades em adapters;
- nenhum segredo ou dado pessoal;
- nenhum bypass de gate ou aprovação;
- nenhuma mudança incompatível sem SemVer e migração;
- não reverta trabalho de outro colaborador sem coordenação.
