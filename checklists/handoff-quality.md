# Quality Gate — Qualidade de Brief e Handoff

- [ ] Projeto, versão, origem e destino estão identificados.
- [ ] A demanda objetiva cabe em uma frase clara.
- [ ] Fatos estão separados de hipóteses.
- [ ] Decisões vigentes estão listadas.
- [ ] Alternativas rejeitadas não reaparecem como recomendação sem nova evidência.
- [ ] Artefatos de entrada existem e são as versões vigentes.
- [ ] Saídas esperadas são identificáveis.
- [ ] Critérios de aceite são verificáveis.
- [ ] Riscos possuem severidade e owner quando aplicável.
- [ ] Questões abertas estão explícitas.
- [ ] O próximo gate foi informado.
- [ ] O receptor consegue executar sem acessar toda a conversa.
- [ ] O handoff não contém segredos ou dados desnecessários.
- [ ] O handoff ainda não foi consumido.

## Vetos

- [ ] Nenhum fato inventado.
- [ ] Nenhuma hipótese apresentada como decisão.
- [ ] Nenhum artefato obsoleto tratado como vigente.
- [ ] Nenhuma mudança de escopo escondida no handoff.

## Veredito

- **PASS:** pronto para consumo.
- **CONCERNS:** risco limitado, explicitado e aceito.
- **FAIL:** contrato incompleto ou contraditório.
- **BLOCKED:** entrada obrigatória indisponível.
